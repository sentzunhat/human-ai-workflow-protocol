# Status Reports

Date-based folder for checkpoint summaries, manager reviews, and context-transfer status artifacts.

Layout:

```
status/
  YYYY/
    MM/
      DD/
        {uuid}/
          status.md
```

Keep entries short, decision-useful, and linked from active work when relevant.
Do not treat this folder as a backlog substitute.

New status artifacts belong under the owning work item's UUID folder. Legacy
date-flat files remain valid until a dedicated migration reconciles them.
