### Context

`core/.hawp/` is the distributable source: the install script
(`distribution/sources/install/script-core.md`) copies `$SRC/.hawp/kit/**`,
LICENSE, and work scaffold into downstream repos. `.hawp/bin/hawp` exists only in
this source repo and is not distributed. Its npm-delegating subcommands require
`librarian/`, which downstream repos do not have — but `hawp uuid` is dependency-free.

---

### Recommended Fix

1. Make the wrapper portable: guard librarian-backed subcommands with an existence
   check and a clear message; `uuid` keeps working everywhere.
2. Mirror the wrapper to `core/.hawp/bin/hawp` (executable).
3. Install script: copy `$SRC/.hawp/bin/hawp` → `.hawp/bin/hawp` + chmod +x;
   regenerate distribution.
4. Repo-wide filename audit against lowercase-hyphen naming (conventional uppercase
   files like README.md, LICENSE, BACKLOG.md, CLAUDE.md, AGENTS.md exempt); fix or
   record offenders.

**What to verify after:**

- [ ] `hawp uuid` works from a repo without librarian/
- [ ] distribution:sync clean; generated guides include bin copy step
- [ ] Filename audit results recorded; fixes validated
- [ ] Full validate suite passes
