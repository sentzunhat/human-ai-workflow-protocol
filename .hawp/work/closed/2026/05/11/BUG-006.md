### Context

The issue is in the validator under `librarian/scripts/validate-hawp-workflow/`, specifically external-root runs using `--hawp-root` and closed-task completeness section detection/reporting.

---

### Analysis

**Root cause (or most likely cause):**
Section detection in `closed-task-completeness` required exact `##`-prefixed headings, so valid files using `### Outcome`, `### Verification`, and `### Close Checklist` were falsely marked missing.

**Directly verified:**

- Fresh reruns reproduced failures for `BUG-156`, `BUG-157`, `BUG-158`, and `TASK-033`.
- Manual file reads confirmed `BUG-156` and `TASK-033` contain required sections at `###` heading level.
- Manual file reads confirmed `BUG-157` and `BUG-158` do not contain required close sections.
- Validator output now includes exact source path for each FAIL/WARN record.

**Inferred (not yet proven):**

- None.

**Scope — what else is affected:**

- Closed-task completeness checks and report rendering in validator output.
