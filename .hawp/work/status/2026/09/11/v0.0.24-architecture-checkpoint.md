# Status Report

## Intent

Step back for the `0.0.24` patch lane and record where the repository architecture stands after the folder normalization, CLI decomposition, provider guidance, and install/update contract work.

## Current State

`0.0.24` is a strong architecture checkpoint. The live branch is `feature/v0.0.24-work-folder-normalization`, the Go version constant reports `0.0.24`, and the `librarian/src` tree now has clear layer groupings:

- `internal/domain` for protocol rules, value models, provider contracts, and pure-ish policy.
- `internal/application` for use cases, workflows, and orchestration.
- `internal/infrastructure` for filesystem, repositories, model backends, clients, archive, markdown, TOML, and self-replacement adapters.
- `internal/bootstrap` for composition root wiring.
- `internal/platform` for CLI, MCP, exit-code, and external interface surfaces.
- `tests` for exported black-box tests that can live outside package internals.

The current shape is simple enough to navigate, visibly scalable, and much closer to the intended ports/adapters direction than the pre-0.0.24 tree.
